# Portfolio RAVELOSON Juvenal — PRO

## Structure
- index.html
- style.css
- script.js
- assets/images/

## Images utilisées
Le code cherche automatiquement ces fichiers avec les extensions .jpg, .jpeg, .png, .webp ou .avif :
- web-developpeur
- DATA SYSTEMS
- IT INFRASTRUCTURE
- DIGITAL TRANSFORMATION
- web-man
- Juvenal-ID

## Lancer dans VS Code
1. Ouvrir le dossier dans VS Code.
2. Vérifier que `assets/images/` contient les images ci-dessus.
3. Ouvrir `index.html` avec Live Server (recommandé) ou directement dans le navigateur.
4. Pour le CV, placer `CV_RAVELOSON_Juvenal.pdf` à côté de `index.html`.

## Traduction
Les boutons FR / EN en haut fonctionnent avec JavaScript et mémorisent la langue dans localStorage.
